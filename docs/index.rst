noisefloat documentation
========================

``noisefloat`` provides NFloat/CESTAC-style stochastic arithmetic for Python
with NumPy, PyTorch, JAX, and TensorFlow backends.

This guide is structured for both users and maintainers:

* fast setup and first run
* operational instructions for day-to-day usage
* practical examples
* complete API reference
* handoff details for maintenance
